# Brenchim

Песенник нашей компании для встреч: тексты и аккорды, сет на вечер, топ компании, видео с YouTube и тюнер.

Сайт: https://v-overkovskiy.github.io/brenchim/

## Что умеет

- **Добавить песню за минуту**: ищет на amdm.ru и Ultimate Guitar, сам подтягивает текст с аккордами и видео с YouTube. Можно вставить ссылку или текст вручную.
- **Режим «Только текст»** для тех, кто поёт, и **«С аккордами»** для тех, кто играет. На телефоне шрифт сам подгоняется под ширину экрана.
- **Транспонирование** (кнопки − / +), схемы аппликатур, автопрокрутка, экран не гаснет, пока открыта песня.
- **Сет на вечер**: собрать список, поменять порядок, перемешать, листать «Далее».
- **Топ компании** по сыгранным, «Давно не играли», отметки «Хочу сыграть» и «Умею играть» (видно, кому дать гитару).
- **Тюнер** через микрофон и эталонные ноты для настройки на слух.
- **Тёмная тема**, работает как приложение (можно «Добавить на главный экран»), открывается без интернета из кэша.

## Как устроено

- `site/` — статический сайт без сборки (HTML + CSS + JS-модули). GitHub Actions публикует его на GitHub Pages при каждом пуше в `main`.
- `site/js/members.js` — участники компании (имя и фото из `site/img/members/`).
- `site/js/config.js` — адрес и публичный ключ Supabase.
- `supabase/schema.sql` — таблицы (songs, marks, plays, sets), открытые правила доступа и функция `proxy_get`: через неё база скачивает страницы с сайтов аккордов (браузер не может сделать это напрямую из-за CORS). Работает только белый список сайтов.

## Частые правки

- **Добавить человека**: положить фото 256×256 в `site/img/members/` и добавить строку в `site/js/members.js`.
- **Поправить или удалить песню**: на странице песни → карандаш. Или в Supabase → Table Editor → `songs`.
- **Свой домен**: Settings → Pages → Custom domain, затем поменять адреса в `og:url` / `og:image` в `site/index.html`.

Сайт открыт для всех, у кого есть ссылка, и закрыт от поисковиков (`noindex`).
